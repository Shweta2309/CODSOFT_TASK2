JobFinder – Online Job Portal

JobFinder is a full-stack job portal web application that connects employers with job seekers. Employers can post and manage job openings, while candidates can explore opportunities and apply for jobs online.

Features

- User Registration and Login
- Role-based Authentication (Employer & Candidate)
- Browse and Search Job Listings
- View Detailed Job Information
- Employer Dashboard
- Post, Edit and Delete Job Openings
- Candidate Dashboard
- Apply for Jobs with Resume Upload
- Email Notifications
- Secure Authentication using JWT
- Responsive User Interface

Installation and Setup

1. Clone the repository.
2. Navigate to the client folder and install dependencies using "npm install".
3. Navigate to the server folder and install dependencies using "npm install".
4. Configure the required environment variables in the server ".env" file:
   - MONGO_URI
   - JWT_SECRET
   - EMAIL_USER
   - EMAIL_PASS
5. Start the backend server using "npm start".
6. Start the frontend development server using "npm run dev".
